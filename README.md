# 墨韻生圖 · AI 丹青工作室

> 整合 Puter.js / Pollinations / Gemini / Hugging Face 的多引擎 AI 文字生圖工具，採用中國水墨風格介面設計。

## 📁 檔案說明

| 檔案 | 說明 |
|------|------|
| `20260605.py` | Streamlit 版本（`streamlit run 20260605.py`） |
| `20260605.html` | 純 HTML 版本（直接瀏覽器開啟） |

## 🚀 快速開始

### Streamlit 版
```bash
pip install streamlit google-genai pillow python-dotenv requests
streamlit run 20260605.py
```
開啟 → http://localhost:8501

### HTML 版
直接用瀏覽器開啟 `20260605.html`（Puter.js / Pollinations 引擎完全免金鑰）

## ✨ 功能特色

- 🔮 **多引擎支援**：NVIDIA Cosmos 3 · FLUX · Gemini 2.5 · Puter.js · Pollinations
- 🖌️ **中國水墨風 UI**：宣紙米黃底、硃砂紅主色、金褐邊框
- 🎨 **風格預設**：吉卜力、日系水彩、可愛 3D、科幻奇幻、復古風、西洋油畫、中國水墨畫
- 📐 **比例支援**：1:1 / 16:9 / 9:16
- 💾 **一鍵下載**生成圖片

## 🔑 API 金鑰取得

- **Gemini**：[Google AI Studio](https://aistudio.google.com/apikey)（免費）
- **Hugging Face**：[HF Settings → Access Tokens](https://huggingface.co/settings/tokens)
